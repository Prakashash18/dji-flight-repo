# Jetson (JetPack / aarch64) dependencies.
#
# Deliberately NOT in this file, and why:
#
#   torch, torchvision  PyPI's aarch64 wheels are CPU-only. Installing them on a
#                       Jetson gives you a server that runs, reports no CUDA, and
#                       does SAHI on six Cortex-A78AE cores — roughly 20x slower
#                       than the GPU, with nothing in the logs saying why.
#                       Install NVIDIA's JetPack wheels first (jetson-setup.sh).
#
#   opencv-python       JetPack ships an OpenCV built with CUDA and GStreamer, in
#                       the system dist-packages. The pip wheel shadows it and
#                       decodes 4K H.265 on the CPU, which on this hardware is a
#                       bigger bottleneck than the inference itself. Use the
#                       system build via a --system-site-packages venv.
#
#   ultralytics         Installed separately with --no-deps so it cannot drag in
#                       the CPU torch wheels behind your back.
#
# Everything below is pure Python or has working aarch64 wheels.
