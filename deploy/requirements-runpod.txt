# RunPod dependencies, for a pod built on a RunPod PyTorch image.
#
# torch and torchvision are deliberately absent. The image already has a build
# matched to its CUDA version — on a Blackwell card (RTX PRO 4500/6000, RTX
# 5090) that is a cu128 build carrying sm_120 kernels, and PyPI's generic wheel
# does not. If pip replaces it, the pod still starts, reports a GPU, and then
# either throws "no kernel image is available for execution on the device" or
# quietly runs on CPU at roughly 1/20th the speed.
#
# ultralytics is installed separately with --no-deps for the same reason: left
# to itself it resolves a torch of its own choosing.
#
# opencv-python IS included here (unlike the Jetson list) — on x86 the pip wheel
# is fine, there is no vendor build to shadow.
